# 🛩️ 飞机大战 (Plane War)

一个使用 Python Pygame 开发的飞机大战游戏，包含 100 个关卡和无尽模式。

## 📦 项目特性

### 核心功能

- ✅ **100个关卡** - 从简单到困难的循序渐进设计
- ✅ **无尽模式** - 无限挑战，难度逐步提升
- ✅ **关卡选择界面** - 可视化的关卡选择，支持翻页
- ✅ **道具系统** - 多种道具增强玩家能力
- ✅ **特效系统** - 爆炸、粒子等视觉效果
- ✅ **最高分记录** - 自动保存和显示最高分

### 优化特性

- 🚀 快速启动 - 关卡按钮延迟加载
- 🎮 双输入方式 - 支持键盘和鼠标
- 🎨 高质量UI - 设计精美的界面
- 🔧 开发工具 - 内置开发者调试面板

## 🎮 游戏操作

### 主界面

- **↑/↓ 或 W/S** - 切换游戏模式
- **回车/空格** - 确认选择
- **ESC** - 退出

### 关卡选择

- **←/→ 或 A/D** - 上一页/下一页
- **↑/↓ 或 W/S** - 选择关卡
- **鼠标点击** - 直接选择或翻页
- **回车/空格** - 进入关卡
- **ESC** - 返回主菜单

### 游戏中

- **方向键** - 移动飞机
- **空格** - 射击
- **ESC** - 暂停

## 🚀 快速开始

### 环境要求

- Python 3.8+
- Pygame 2.0+

### 安装依赖

```bash
pip install pygame
```

### 运行游戏

```bash
# 普通模式
python main.py

# 开发者模式（包含调试工具）
python dev_main.py
```

## 🎨 游戏参数配置

所有游戏参数都在 `constants.py` 中定义：

```python
# 窗口设置
WIDTH = 800
HEIGHT = 600
FPS = 60

# 玩家设置
PLAYER_SPEED = 5
PLAYER_SHOOT_CD = 8  # 帧数

# 敌人设置
MAX_ENEMIES = 40
ENEMY_SPAWN_INTERVAL = 55

# 关卡难度
MAX_LEVEL = 100
```

## 🔧 开发者模式

启动 `dev_main.py` 可以使用开发者工具：

- **加分按钮** - 快速增加得分
- **无敌模式** - 开关玩家无敌状态
- **暂停陨石** - 暂停陨石生成
- **生成陨石** - 手动生成陨石
- **生成道具** - 手动生成道具
- **调整难度** - 实时调整游戏速度

## 📊 游戏规则

### 关卡模式

- 完成特定目标得分进入下一关
- 得分目标根据关卡难度递增
- 通过所有100个关卡获得最终胜利

### 无尽模式

- 无限生成陨石，难度逐步提升
- 每隔一段时间提高游戏难度
- 最高分会自动保存

### 道具系统

- **加分道具** - 快速获得1000分
- **护盾道具** - 承受一次伤害
- **修复道具** - 恢复部分生命值
- **加速射速** - 提升射击速度
- **增加弹道** - 同时射出多发子弹
