# 飞机大战 (Plane War)

一个用 Python + Pygame 写的飞机大战游戏，包含 100 个关卡和一个无尽模式。

## 快速开始

环境要求：Python 3.8+（在 3.11 上开发和测试）。

```bash
pip install -r requirements.txt

# 普通游玩
python main.py

# 开发者模式（带调试面板和快捷键）
python dev_main.py
```

两个入口都要在项目根目录运行，`plane_war` 包才能被找到。

## 游戏玩法

### 模式

- **关卡模式** — 从选中的关卡开始，达到目标分数即通关并自动进入下一关。第 N 关的目标分数是 `N × 1000`，关卡越靠后陨石生成越密集。打满 100 关即通关全部内容。
- **无尽模式** — 陨石无限生成，每 600 帧提升一次难度。生命耗尽时结算，破纪录会写入最高分。

### 操作

| 场景 | 按键 | 作用 |
| --- | --- | --- |
| 主界面 | ↑/↓ 或 W/S | 切换模式 |
| 主界面 | 回车 / 空格 | 确认 |
| 关卡选择 | ←/→ 或 A/D | 上一页 / 下一页（首尾循环） |
| 关卡选择 | ↑/↓ 或 W/S | 在本页内选关（首尾循环） |
| 关卡选择 | 鼠标 | 点一次选中，再点一次进入 |
| 游戏中 | ↑↓←→ 或 WASD | 移动（飞机只能在屏幕下三分之一活动） |
| 游戏中 | 空格 | 射击（按住连发） |
| 任意界面 | 退出键 | 弹出退出确认，Y 退出 / N 继续 |

### 道具

陨石被击碎时按尺寸和难度概率掉落，陨石越大掉率越高、可掉的种类越多。

| 道具 | 效果 |
| --- | --- |
| 加分 | 当前分数 +10% |
| 护盾 | 护盾值 +25（上限为生命上限的两倍），受伤时优先抵扣 |
| 治疗 | 生命 +20，不超过当前生命上限 |
| 加快射速 | 射击冷却 ×0.9，可叠加 |
| 增加弹道 | 弹道数 +1，可叠加 |

### 受伤机制

撞到陨石会按陨石等级扣 5~85 点血，同时按伤害的 20% **永久压低本条命的生命上限**（最多压到原上限的 1/4）。掉一条命后生命上限才会恢复。所以尽量别硬吃伤害。

```text
plane-war/
├── main.py                  游戏入口
├── dev_main.py              开发者模式入口
├── requirements.txt
├── plane_war/               游戏代码包
│   ├── paths.py             项目内所有磁盘路径的唯一来源
│   ├── core/                核心层
│   │   ├── game.py          游戏总控：搭建子系统、调度界面和两个模式的主循环
│   │   ├── constants.py     纯数值配置（窗口、颜色、玩家、陨石、道具数值）
│   │   ├── rules.py         可计算的规则公式（生成间隔、目标分数、难度推进）
│   │   ├── logs.py          带时间戳的终端日志
│   │   └── utils.py         与 pygame 无关的通用函数
│   ├── world/               世界层
│   │   ├── entities.py      玩家、陨石、子弹、道具
│   │   ├── systems.py       射击、生成、碰撞、伤害、道具结算
│   │   └── effects.py       爆炸粒子
│   ├── ui/                  界面层
│   │   ├── interfaces.py    主界面、关卡选择、结算、退出确认
│   │   ├── renderer.py      游戏内绘制（背景、状态栏、血条、实体兜底外观）
│   │   ├── asset_manager.py 字体和图片加载、子弹图片组轮换
│   │   └── widgets.py       按钮底图绘制
│   ├── data/
│   │   └── storage.py       无尽模式最高分读写（已将最高分记录由user_data/README.md改为user_data/high_score.json）
│   └── dev/
│       └── devtools.py      开发者面板和调试快捷键
├── assets/pictures/         图片资源
│   ├── plane/               玩家飞机
│   ├── bullets/             子弹图片，每个子目录是一个轮换组
│   ├── meteorite/           陨石原图
│   ├── powerup/             道具图标
│   └── level_button/        关卡按钮底图
├── user_data/               本地存档
└── docs/                    开发文档
    ├── DEVELOPMENT.md       模块职责、数据流、扩展指南
    └── CONFIG.md            配置参数速查
```

分层的依赖方向是单向的：`core` → `world` → `ui`，`dev` 只在开发者入口加载，普通游玩完全不导入。

## 调参

游戏参数集中在两个文件，改之前先确认属于哪一类：

- [plane_war/core/constants.py](plane_war/core/constants.py) — 写死的数值：窗口尺寸、帧率、颜色、玩家速度和射击冷却、陨石五个等级的尺寸/血量/得分/速度/伤害、道具效果数值、实体数量上限。
- [plane_war/core/rules.py](plane_war/core/rules.py) — 按关卡算出来的规则：陨石生成间隔、通关目标分数、无尽模式难度推进节奏、最高分写盘的检查点。
